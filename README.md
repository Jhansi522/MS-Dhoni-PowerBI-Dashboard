# Captain Cool – MS Dhoni Career Insights

## Project Overview

This Power BI dashboard analyzes the cricket career of MS Dhoni using IPL and International cricket statistics.

## Dashboard Highlights

- IPL Runs by Season
- International vs IPL Runs
- Wicketkeeping Performance
- Strike Rate Analysis
- Boundary Distribution
- Captaincy Achievements

## Tools Used

- Power BI
- Microsoft Excel

## Key Insights

- Peak IPL performance observed between 2013–2019
- ODI format contributed the highest international runs
- Strong wicketkeeping performance across formats
